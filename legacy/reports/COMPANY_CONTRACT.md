# Measured handoffs and implementation artifacts

This extension addresses the actual failed company pilot. It does not establish autonomous research efficiency, profitable strategies, beneficial organizational learning, or fund readiness.

## What changed

Before director allocation, the desk profiles availability-selected development frames and supplies the measured data contract to the director, scientist and engineer. Selection uses cache availability rather than returns. The contract states supported holding horizons, model date relationships and observed segment lengths. Numerical state and labels reset at reconstruction boundaries; a full day does not imply a continuous full-day history. Cooperative stop/deadline checks apply between frames.

The actual prepared November 1, 13 and 25 frames each contain 86,400 observations in 96 segments of 900 rows. With 300-second holding, the maximum observed feasible warmup is 597 rows after entry delay and label maturity. These are measured bounds on these frames, not guarantees about every future frame. Planning does not expose forecasts, PnL, holdout data or promotion evidence.

The scientist must return a validated `strategy_spec` alongside its hypothesis, design and ablation. A trusted metadata feasibility check rejects an incompatible fitted proposal before accepting the handoff. Rejection supplies specific feedback within the same finite role budget. It does not fit generated code or silently substitute a different model recipe. Versioned scientist task identities prevent older unstructured checkpoints from satisfying this new contract.

The engineer's company task uses immutable artifact tools:

1. `build_candidate(spec, code)` persists a PROPOSED draft and returns its exact ID, code hash and specification hash. Building is not submission or economic evidence.
2. `revise_candidate(candidate_id, spec_changes, code?, replace_model?)` creates a validated descendant. Ordinary model changes merge explicitly; `replace_model=true` starts the requested recipe from defaults. Prior artifacts remain intact.
3. `check_candidate(candidate_id)` runs the real bounded numerical worker and checks prefixes, schema and bounds. It is not a backtest or proof of fitting compatibility.
4. `candidate_feasibility(candidate_id)` checks the stored recipe against actual development metadata without fitting or economic replay.
5. `walk_forward_candidate` or `experiment_candidate` replays the exact stored artifact. Economic evidence comes from these measured results, not from successful compilation or draft creation.
6. Submission references the actual artifact ID. Deterministic validation and subsequent promotion gates still apply.

The company engineer is advertised this ID workflow; legacy full-code tools remain supported for other callers. The runtime enforces the tools advertised for each turn, including a final turn with no tools. A resumed unmeasured draft remains in repair mode. Successful economic replay checkpoints can enter measured finalization. Role, campaign and seal restrictions remain enforced, and cached results bind the actual stored identity, including semantic duplicates.

## Recovery and direction changes

Stopped cycles become PAUSED, failed cycles become FAILED, and resumption reuses their checkpoints. Operational interruption does not reject a strategy economically. After an explicit direction-change decision, use:

```powershell
python -m quantdesk abandon-cycle CAMPAIGN_ID --reason 'Measured history cannot support this mechanism; choose a new mission'
```

Abandonment rejects a live owning task or sealed campaign, records ABANDONED plus an operational lesson, and retains code, requests, tasks and measurements. A subsequent research start creates a new cycle rather than silently reusing the old mission. The original token allowance and usage remain unchanged.

The failed pilot campaign `2b22519842f6` has now explicitly abandoned cycle `6792345b30f3`. Its three operator attempts failed, with zero complete cycles, 18 real provider requests and 644,405 actual/charged tokens. The original 750,000 allowance leaves 105,595 tokens. No fourth pilot recovery, budget increase, new cycle or paid inference was launched during this verification.
